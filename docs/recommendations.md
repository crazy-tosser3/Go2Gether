# Рекомендации мероприятий

Локальная эвристика без машинного обучения и внешних сервисов. Код: `Services/RecommendationService.java` (сбор профиля и кандидатов), `recommendation/RecommendationEngine.java` (подсчёт баллов), тесты — `src/test/java/com/example/STOLOTO/recommendation/RecommendationEngineTest.java`.

## Эндпоинты

| Запрос | Доступ | Что возвращает |
|---|---|---|
| `GET /api/v1/recommendations/events?limit=&lat=&lng=` | публично; с токеном — персонально | Подборка будущих опубликованных мероприятий с `score` и кодами причин `reasons` |
| `GET /api/v1/events/{id}/similar?limit=` | публично (если карточка доступна) | Похожие мероприятия; ответ кэшируется в регионе ленты |

`limit` — по умолчанию 10, максимум 50. Кандидаты — опубликованные мероприятия в горизонте 60 дней, не больше 500.

## Персональная подборка

Для авторизованного пользователя исключаются мероприятия, на которые у него уже есть любая запись, и мероприятия, которые он организует сам или через свою организацию.

Профиль собирается из:

- интересов профиля (`user_sports`), общего уровня и уровней по направлениям (`user_sport_levels`), удобного времени (`user_preferred_times`), радиуса (`radius_km`), города;
- истории записей (до 100 последних со статусом `CONFIRMED`, `PENDING`, `WAITLIST`; неподтверждённые весят 0.6): любимые направления, категории, города, знакомые организаторы;
- «соседей» — людей, с которыми пользователь был подтверждённым участником одних мероприятий.

Без токена используется пустой профиль: работают только популярность, близость по времени, заполненность и расстояние до `lat`/`lng`, если они переданы.

## Баллы

| Фактор | Вес | Код причины |
|---|---|---|
| Направление в интересах | 3.0 | `interest` |
| Направление из истории | 2.5 × доля | `played_before` |
| Категория из истории | 1.0 × доля | — |
| Город из истории или профиля | 2.0 × доля | `same_city` |
| Другой город (если город известен) | −1.0 | — |
| Расстояние до точки | 2.0 × e^(−км/радиус), радиус из профиля или 10 км | `nearby` (в пределах радиуса) |
| Уровень совпадает / отличается на 1 / на 2 | +1 / 0 / −1 | `level_match` |
| Удобное время | 1.0 | `preferred_time` |
| Идут знакомые участники | 1.2 × log(1 + Σ log(1 + встреч)) | `friends_going` |
| Знакомый организатор | 1.0 | `familiar_organizer` |
| Популярность | до 0.6 | `popular` (от 10 подтверждённых) |
| Скоро начнётся | 1 / (1 + дней/7) | `soon` (до 3 дней) |
| Мест нет | −1.5 | — |

Похожие мероприятия считаются от целевого: то же направление (4.0, `same_sport`) или та же категория (1.5, `same_category`), расстояние или город, уровень, коэффициент Жаккара по составу участников (4.0, `shared_participants`), тот же организатор (1.5, `same_organizer`), плюс популярность, срок и заполненность.

В ответ попадают причины с вкладом не меньше 0.3, по убыванию вклада. Итоговый список диверсифицируется: каждое следующее мероприятие того же направления получает множитель 0.85^n.

## Ограничения

- Веса подобраны вручную и не проверялись на реальных данных.
- Персональная подборка не кэшируется и считается при каждом запросе по всем кандидатам (до 500).
- У демо-пользователей, созданных миграциями, интересы (`user_sports`) пустые — подборка строится по истории записей и городу. Интересы можно задать через `PATCH /api/v1/users/me` (`sport_ids`).
